批量导入 Markdown / H5

支持一次选择多个 `.md` / `.html` 文件。Markdown 按二级标题拆章；已有折叠结构的 H5 按 accordion 解析。

专用 HTML 教程导入

针对带侧栏目录 + main-content + h2 章节的教程 HTML（如《SQL Server 编程教程》）。每个 h2 自动变成一节折叠卡片，代码块 / 表格 / tip·warn·info 框一并转换。
